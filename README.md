# Study Quiz v3.0.1 — LPIC-1 101

LPIC-1 Exam 101（101-500 / Version 5.0）向けのローカルファースト学習PWAです。試験日、復習期限、弱点、回答速度、利用可能時間、選択した出題範囲を使って学習セッションを構成します。

## 主な機能

- LPIC-1 101のオリジナル初期問題100問（23 objectivesを網羅）
- 上位の「試験枠」→トピック→理解度→出題方法→個別問題、の順で出題対象を指定
- 設定画面で出題条件の初期値を保存し、ホームと学習画面へ反映
- おすすめ、新規、復習期限、苦手、条件一致、個別指定の学習
- 日別回答数と、未学習・学習中・習得済みの推移グラフ
- ライト／ダーク／端末連動テーマ
- 初回のみ表示する操作ガイドと、主要画面の「？」ヘルプ
- FSRS復習、弱点分析、試験直前戦略、中断再開
- CSV一括登録、問題管理、修正提案、メモ、完全バックアップ
- iPhoneのセーフエリアを考慮したPWA・オフライン対応

## 必要環境

- Node.js 20.19以上（CIはNode.js 24）
- npm
- E2E実行時はChromeまたはChromium

## データモデルと移行

- IndexedDB `study-quiz` のバージョンは2です。
- `examScopes` オブジェクトストアが試験枠マスターです。初期値は `lpic101` のみです。
- 旧 `linuc101` 設定は `lpic101` として互換読込し、次回保存時に移行します。
- 旧問題に `examScopeId` がない場合は `lpic101` を補完します。
- localStorageスキーマはversion 6、完全バックアップ形式もversion 6です。version 2〜5は復元時に現行形式へ補完します。

## 問題CSV

`examScopeId` 列を使用できます。省略時は `lpic101` です。例は `sample_questions.csv` を参照してください。

## データ保護方針

- 主要データは端末内に保存します。
- 問題削除は原則アーカイブで行い、履歴参照を維持します。
- AI支援は利用者の送信操作時だけ外部APIへ送信します。
- 完全バックアップにAPIキーとUIガイド表示状態は含めません。

変更内容、移行、既知の制約は `UPGRADE_REPORT.md`、詳細仕様は `doc/` を参照してください。
