# 適応型資格試験学習PWA 全体要件定義書

- 文書版: 1.0.0
- 対象: Study Quiz 最終版
- 基準日: 2026-10-05

## 1. 目的
資格試験の問題演習を、試験日、復習期限、重要度、弱点、回答速度および利用可能時間に基づいて最適化する。利用者が「今日何を学ぶべきか」を判断しなくても、必要な学習を継続できることを目的とする。

## 2. 想定利用者
LPIC-1 Exam 101を受験する個人利用者。初期配布問題はLPICだけとし、将来拡張は試験枠マスターで分離する。

## 3. 基本方針
1. iPhoneを主対象とするPWAとして提供する。
2. ログインを必須とせず、主要データを端末内に保持する。
3. 主要な学習機能はオフラインでも継続できる。
4. 試験日までの有効学習日から必要ペースを算出する。
5. 合否を断定せず、実績、遅れ、必要量を提示する。
6. AI出力は補助情報とし、自動で問題へ確定反映しない。

## 4. 対象範囲
### 4.1 対象
- 初回設定、設定変更
- ホーム、下部ナビゲーション、モバイルUI
- 問題管理、CSV一括登録
- 学習計画、セッション生成、問題回答、結果、中断再開
- FSRS、弱点分析、忘れかけ検出、試験直前戦略
- 履歴、統計、進捗予測、ストリーク
- 間違いノート、お気に入り、メモ、修正提案
- AI質問支援、テンプレート、ファクトチェック補助
- 完全バックアップ、復元、PWA更新、オフライン利用

### 4.2 未対応または対象外
- アカウント、認証、権限管理
- クラウド同期、複数端末間の自動同期
- サーバー側でのAPIキー保護
- 完成版の類似問題自動生成
- XLSX、JSONによる問題一括登録
- Push通知による学習リマインド

## 5. 主要業務ルール
- 試験日、学習しない日、バッファ率から有効学習日数を求める。
- 日次新規上限、総問題上限、最低問題数、任意の時間上限を設定できる。
- FSRS期限、弱点、重要度、試験日緊急度、新規問題を統合して優先度を算出する。
- 同一セッション内で同一問題を重複出題しない。
- 回答速度は補助指標とし、正誤とFSRS評価から分離する。
- 修正提案とAI提案は承認前に問題本体を変更しない。

## 6. UI・UX要件
- iPhone縦長画面、Dynamic Island、画面角、ホームインジケータの安全領域を考慮する。
- ホームへの機能集中を避け、下部固定ナビゲーションで主要画面へ遷移する。
- 大見出しを抑制し、学習中は問題、選択肢、解説を優先表示する。
- 固定UIと本文を重ねない。
- 選択、正解、不正解、無効状態は色以外の表現も併用する。

## 7. データ要件
- 問題、履歴、問題状態、FSRS状態、設定、メモ、提案、中断セッションを保持する。
- 設定はIndexedDBを利用し、互換性維持のため一部にlocalStorageを併用できる。
- 回答履歴、問題状態、中断位置の不整合を抑止する。
- 完全バックアップへAPIキーを含めない。
- 復元失敗時に既存データを保護する。

## 8. 非機能要件
### 8.1 可用性
- オフラインで登録済み問題の学習、回答保存、統計参照ができる。
- 学習中断後に位置と成績を復元できる。

### 8.2 性能
- モバイルで不要な全件走査を避ける。
- 大量CSVは登録前に検証結果と対象件数を確認できる。

### 8.3 セキュリティ・プライバシー
- 学習データは原則端末内に保持する。
- 外部AI送信前に内容と注意事項を明示する。
- APIキーをバックアップへ出力しない。

### 8.4 品質・保守性
- TypeScript型検査、テスト、プロダクションビルドを一括実行できる。
- 要件ID、設計ID、テストIDを追跡できる。
- 保存形式変更時は旧形式からの移行または互換読込を行う。

## 9. 全体受入条件
- 各機能要件書の受入条件を満たす。
- `npm run check` と `npm run build` が成功する。
- iPhone PWAで固定UIが本文を隠さない。
- オフライン、更新通知、バックアップ復元、中断再開を実機確認する。


## 10. v3.0追加要件（2026-10-06）
- 初期配布問題はLPIC-1 Exam 101だけとし、試験枠をカテゴリより上位の独立マスターとして保持する。
- 設定画面で試験枠、トピック、理解度、出題方法、個別問題の初期値を保存できる。
- 学習画面で上記条件を一時変更し、実際のセッション生成へ反映できる。
- 日別回答数および未学習・学習中・習得済み件数の時系列を表示する。
- ライト、ダーク、端末連動テーマを選択できる。
- 初回のみ操作ガイドを表示し、主要画面からコンテキストヘルプを開ける。
- ホーム、管理、その他はiPhone縦画面で過度な空白を残さず、有用な要約情報を表示する。
