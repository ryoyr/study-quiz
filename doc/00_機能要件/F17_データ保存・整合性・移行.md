# F17 データ保存・整合性・移行 要件定義書

- 機能ID: F17
- 対応状況: **一部対応**
- 対象版: Study Quiz v1.2.0

## 1. 目的
データ保存・整合性・移行に必要な利用者価値と業務ルールを定義する。

## 2. 機能要件
- F17-R01: 端末内に問題、履歴、状態、設定を保存する。
- F17-R02: 設定をIndexedDBへ保存する。
- F17-R03: 回答履歴、問題状態、進捗の不整合を抑止する。
- F17-R04: 保存形式の版を識別して移行または互換読込する。

## 3. 受入条件
- F17-A01: 保存失敗を通知する。
- F17-A02: 再起動後に主要データを復元する。

## 4. 制約・残課題
- Storage Key Registryによる物理キー・バックアップ対象の一元管理は対応済み。
- 論理トランザクションはRegistry未登録キーを拒否する。
- 全データのIndexedDB正本化は未完了で、一部はlocalStorageを利用する。

## 5. 設計書更新時の留意点
- 本書の要件IDを画面、コンポーネント、サービス、データ、テストへ紐付ける。
- 状況変更時は根拠となる実装ファイルとテスト結果を記録する。
