# F02 ホーム・ナビゲーション・モバイルUI 要件定義書

- 機能ID: F02
- 対応状況: **対応済**
- 対象版: Study Quiz v1.0.0

## 1. 目的
ホーム・ナビゲーション・モバイルUIに必要な利用者価値と業務ルールを定義する。

## 2. 機能要件
- F02-R01: ホームは今日の学習判断に必要な情報へ絞る。
- F02-R02: 下部固定ナビゲーションから主要機能へ遷移できる。
- F02-R03: safe-areaへ対応する。
- F02-R04: 大見出しを抑制し内容領域を優先する。

## 3. 受入条件
- F02-A01: iPhoneのスタンドアロン表示で上下の安全領域に重ならない。
- F02-A02: 主要機能へ2操作以内で到達できる。

## 5. 設計書更新時の留意点
- 本書の要件IDを画面、コンポーネント、サービス、データ、テストへ紐付ける。
- 状況変更時は根拠となる実装ファイルとテスト結果を記録する。


## v3.0追補
- FR-F02-11: 初回の主要画面表示時だけ、基本操作を示すフローティングガイドを表示すること。
- FR-F02-12: 主要画面から「？」ボタンでコンテキストヘルプを表示できること。
- FR-F02-13: iPhone縦画面の下部余白には、出題条件・進捗・教材情報など意思決定に役立つ内容を配置すること。

## v4.0追補
- FR-F02-14: 主要機能は意味が一貫したSVGアイコンとテキストラベルを併記し、絵文字・記号だけに依存しないこと。
- FR-F02-15: 現在地、オンライン状態、試験までの日数、今日の達成状況を共通Chromeで確認できること。
- FR-F02-16: ホームから学習条件、記録、表示設定へ直接遷移でき、主要な次行動を1操作で開始できること。
- FR-F02-17: キーボードフォーカス、スキップリンク、縮小モーション、safe-area、320px幅を考慮すること。
