# F11 間違いノート・お気に入り・メモ 要件定義書

- 機能ID: F11
- 対応状況: **対応済**
- 対象版: Study Quiz v1.0.0

## 1. 目的
間違いノート・お気に入り・メモに必要な利用者価値と業務ルールを定義する。

## 2. 機能要件
- F11-R01: 誤答問題を間違いノートで参照できる。
- F11-R02: お気に入り登録と解除ができる。
- F11-R03: 問題メモを保存・編集できる。
- F11-R04: 対象問題から再学習できる。

## 3. 受入条件
- F11-A01: 再起動後も内容を維持する。
- F11-A02: 問題削除時に関連表示が破綻しない。

## 5. 設計書更新時の留意点
- 本書の要件IDを画面、コンポーネント、サービス、データ、テストへ紐付ける。
- 状況変更時は根拠となる実装ファイルとテスト結果を記録する。
