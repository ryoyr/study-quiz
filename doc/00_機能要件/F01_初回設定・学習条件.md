# F01 初回設定・学習条件 要件定義書

- 機能ID: F01
- 対応状況: **対応済**
- 対象版: Study Quiz v1.0.0

## 1. 目的
初回設定・学習条件に必要な利用者価値と業務ルールを定義する。

## 2. 機能要件
- F01-R01: 試験名、試験日、日次新規上限、日次総問題上限、バッファ率、即答閾値を設定できる。
- F01-R02: 学習しない日、最低問題数、時間上限を設定できる。
- F01-R03: 入力値検証と保存失敗表示を行う。
- F01-R04: 保存済み設定を再読込して変更できる。

## 3. 受入条件
- F01-A01: 有効値の保存後にホームへ遷移する。
- F01-A02: 試験日、上限、重複予約日の不正値を拒否する。

## 5. 設計書更新時の留意点
- 本書の要件IDを画面、コンポーネント、サービス、データ、テストへ紐付ける。
- 状況変更時は根拠となる実装ファイルとテスト結果を記録する。
