
# F18 品質・エラー処理・アクセシビリティ 要件定義書

- 機能ID: F18
- 対応状況: **一部対応（ビルド構成・共通エラー処理・単体試験を改善）**
- 対象版: Study Quiz v1.1.0

## 1. 目的
品質・エラー処理・アクセシビリティに必要な利用者価値と業務ルールを定義する。

## 2. 機能要件
- F18-R01: 入力、保存、通信エラーを説明する。
- F18-R02: 型検査、テスト、ビルドを一括実行できる。
- F18-R03: キーボードとフォーカスを阻害しない。
- F18-R04: 色だけに依存しない状態表現を用いる。

## 3. 受入条件
- F18-A01: npm run checkとnpm run buildが成功する。
- F18-A02: 主要画面に操作不能な重なりや横スクロールがない。

## 4. 制約・残課題
- 自動アクセシビリティ試験と網羅的E2E試験は未対応。

## 5. 設計書更新時の留意点
- 本書の要件IDを画面、コンポーネント、サービス、データ、テストへ紐付ける。
- 状況変更時は根拠となる実装ファイルとテスト結果を記録する。


## 6. 実装・試験根拠
- TypeScript構成: `tsconfig.json`、`tsconfig.app.json`、`tsconfig.node.json`
- 共通エラー処理: `src/components/ErrorBoundary.tsx`、`src/main.tsx`
- 回帰試験: `tests/*.test.ts`
- 残課題: Playwright等のE2E、axe等の自動アクセシビリティ試験、iPhone実機の狭幅・文字拡大・VoiceOver受入。
