# F13 AI学習支援・ファクトチェック 要件定義書

- 機能ID: F13
- 対応状況: **一部対応**
- 対象版: Study Quiz v1.0.0

## 1. 目的
AI学習支援・ファクトチェックに必要な利用者価値と業務ルールを定義する。

## 2. 機能要件
- F13-R01: 問題コンテキスト付き質問文を生成または送信できる。
- F13-R02: 質問テンプレートと利用者テンプレートを管理できる。
- F13-R03: 詳細解説、自由質問、ファクトチェック補助を提供する。
- F13-R04: AI提案を自動反映しない。

## 3. 受入条件
- F13-A01: APIキーをバックアップへ含めない。
- F13-A02: 外部送信前に注意事項を確認できる。
- F13-A03: 通信失敗時も学習データを破損しない。

## 4. 制約・残課題
- 直接通信方式とコピー方式の実装世代が混在していたため最終実機確認が必要。APIキーのサーバー保護は未対応。

## 5. 設計書更新時の留意点
- 本書の要件IDを画面、コンポーネント、サービス、データ、テストへ紐付ける。
- 状況変更時は根拠となる実装ファイルとテスト結果を記録する。
