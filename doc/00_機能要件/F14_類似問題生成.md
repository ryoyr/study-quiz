# F14 類似問題生成 要件定義書

- 機能ID: F14
- 対応状況: **対応済（コピー＆レビュー方式）**
- 対象版: Study Quiz v1.1.0

## 1. 目的
既存問題を基に類似問題案を作成し、利用者が内容を確認・編集した後にのみ問題庫へ登録できるようにする。

## 2. 機能要件
- F14-R01: 既存問題を選択し、問題コンテキストとJSON出力契約を含む類似問題生成プロンプトを作成できる。
- F14-R02: 外部AIのJSON回答を検証し、確認・編集可能な下書きとして表示できる。
- F14-R03: 内容確認チェック後の利用者操作でのみ登録し、元問題を自動変更しない。
- F14-R04: 問題ID、問題文、選択肢、正解位置、重要度、難易度、重複を登録前に検証する。

## 3. 受入条件
- F14-A01: プロンプト作成時点では端末内データを変更せず、外部AIへ自動送信しない。
- F14-A02: 不正JSON、範囲外正解、重複選択肢、元問題と同一の問題文を拒否する。
- F14-A03: 自動採番した一意なIDを使用し、確認済みの場合だけ問題庫へ登録する。
- F14-A04: 登録後も元問題の内容が変化しない。

## 4. 制約・残課題
- APIキー保護が必要な直接通信方式は採用せず、コピー＆ペースト方式とする。
- AI出力の事実性は利用者が出典・解説を確認する。自動承認は行わない。
- 実機での文字拡大、画面回転、VoiceOver確認は別途受入試験で実施する。
